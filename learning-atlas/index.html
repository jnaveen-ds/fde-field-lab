ORCHESTRATION

LangGraph makes changing workflows explicit.

Use it for branching, checkpoints, bounded loops, human interruption, and recovery—not because every LLM application needs a graph.

SHARED CONTRACT

State

The typed snapshot passed between nodes.

  • ticket and tenant IDs
  • classification and risk
  • evidence references
  • draft and confidence
  • approval and errors
Not state: secrets, database clients, all documents, or unlimited conversation history.

WORK UNIT

Node

Reads state, performs one responsibility, returns a small update.

ROUTING

Edge

Chooses the next node from explicit state and deterministic policy.

DURABILITY

Checkpointer

Persists state by run ID so a workflow can pause and resume.

CONTROL

Interrupt

Stops before a high-impact action and waits for real authorization.

Use LangGraph when

  • approval pauses execution
  • runs must resume after failure
  • routes and bounded loops exist
  • you evaluate state transitions

Do not use it when

  • one model call solves the task
  • a short pipeline is already clear
  • it hides unclear requirements
  • durable state cannot be operated

WHY METADATA?

Provenance and access

Stable chunk IDs, source, version, tenant, ACL, page, and section make results explainable, updateable, and enforceable.

SKIP VECTOR DB WHEN

Exact systems are better

Use SQL or keyword lookup for authoritative records, tiny corpora, strict filters, or when retrieval quality cannot yet be evaluated.

05

FIELD RULES

Complexity must earn its place.

These controls turn an agent demonstration into an operable FDE solution.

MODEL ROUTING

Smallest model that meets the evaluated threshold

Route by task, risk, quality, latency, cost, and availability. Define malformed-output and provider-outage fallbacks.

TOOLS

Typed contracts and risk classes

Separate reads from writes. Validate arguments, authorize in code, and return machine-readable results.

STATE & MEMORY

Transient is not durable or retrieved

Keep workflow state, business history, and long-term knowledge in stores suited to their access and retention needs.

MULTI-AGENT

Separate responsibility, not personality

Use typed handoffs, narrow permissions, budgets, and termination. Compare against a single-agent baseline.

MCP

Standard protocol, not a security boundary

Hosts discover tools and resources from servers. Authentication, authorization, approval, and validation remain your responsibility.

EVALUATION

Inspect outcome and trajectory

Evaluate routes, retrieval, context, tool arguments, retries, approvals, final quality, latency, cost, and safety.

RELIABILITY

Every dependency will fail

Timeout, classify errors, retry only safe retryable operations, back off, reconcile side effects, and test degraded modes.

OBSERVABILITY

Trace decisions without leaking data

Record step metadata, routes, IDs, timing, tokens, cost, and outcomes. Redact prompts, documents, secrets, payloads, and PII.

THE FDE TEST
