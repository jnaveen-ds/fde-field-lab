## Status meanings

- **Not started:** no learning evidence yet.
- **In progress:** lesson or exercise has started, but the completion gate is not met.
- **Complete locally:** gate and review passed; changes have not been pushed.
- **Pushed:** commit and immutable `day-NN-complete` tag are available on GitHub.
