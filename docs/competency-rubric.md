# FDE Competency Rubric

Use this rubric after every milestone. A skill advances only when the repository contains reviewable evidence.

| Level | Meaning |
| --- | --- |
| 0 — Not started | No evidence yet |
| 1 — Guided | Can complete a defined task with instructions |
| 2 — Independent | Can choose and implement a sound approach, then explain trade-offs |
| 3 — Field-ready | Can deliver and operate it under ambiguous customer constraints |

## Competencies

| Area | Field-ready evidence |
| --- | --- |
| Discovery | Interview notes, workflow map, validated requirements, assumptions corrected by feedback |
| Product judgment | Prioritized scope, explicit non-goals, measurable customer outcome |
| Software engineering | Maintainable vertical slices, useful tests, debugging evidence, clear contracts |
| Data engineering | Sound schema, migrations, data-quality checks, safe lifecycle handling |
| AI engineering | Baselines, model-routing evidence, labelled evals, quality/latency/cost results, failure analysis |
| Agent engineering | Typed tools, separated state/memory, controlled orchestration, trace evals, deterministic approvals, evaluated benefit |
| Integration | Authenticated APIs/webhooks, reconciliation, rate-limit and failure handling |
| Security | Threat model, least privilege, tenant isolation, adversarial tests, auditability |
| Production | Automated delivery, sanitized agent traces, SLOs, fallbacks, rollback, recovery and load evidence |
| Communication | Clear design review, customer demo, runbook, and concise incident/update writing |
| Impact | Baseline, target, observed result, adoption evidence, and iteration from feedback |

## Evidence record

For each completed milestone, add a short record containing:

```markdown
## YYYY-MM-DD — Milestone name

- Customer outcome:
- What I built:
- Key decision and trade-off:
- Verification performed:
- Failure or feedback discovered:
- Metric before/after:
- What I would change next:
- Evidence links:
```

Self-ratings without linked evidence do not count. It is acceptable to remain at Level 1 while learning; the objective is visible improvement, not inflated scores.
